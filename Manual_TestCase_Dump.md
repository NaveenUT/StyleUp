## How to use this file

One test case per table row, one line per row — `grep` returns whole cases.

```bash
grep '^| HOM-015' Manual_TestCase_Dump.md          # one case by ID
grep -A 200 '^## Module: Cart' Manual_TestCase_Dump.md   # a whole module
grep '| Boundary Value |' Manual_TestCase_Dump.md   # every case of one technique
grep '| P0 |' Manual_TestCase_Dump.md               # every P0 case
```

**Columns.** `TC ID`, `Sub-Module`, `Test Scenario`, `Pre-conditions`, `Test Steps`, `Test Data`, `Expected Result`, `Priority`, `Type`, `Technique`. The `Module` value is the section heading, not repeated per row.

**Not included.** The source has four execution-tracking columns — `Status`, `Actual Result`, `Defect ID`, `Remarks` — empty for all 797 rows. They are omitted here; this is a design register, not an execution log.

**Steps** use ` → ` as the step separator, exactly as authored in the source.
